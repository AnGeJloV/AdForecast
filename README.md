# AdForecast

Программное средство прогнозирования окупаемости маркетинговых кампаний на основе методов машинного обучения. Курсовой проект по дисциплине «Технологии проектирования сложных информационных систем», БГУИР.

## Возможности

- **Прогноз окупаемости до старта:** на основе параметров кампании (канал, бюджет, длительность, месяц старта) строится прогноз — вернётся ли вложение, коэффициент возврата, интервал 80 %, срок окупаемости.
- **Сравнение вариантов:** два сценария бюджета и длительности «в лоб», с подсветкой выгодного варианта и выбором модели (своя + общая / только свои / только общая).
- **Загрузка выгрузок рекламных кабинетов:** CSV и XLSX, автоматическое распознавание колонок, разделителя, кодировки и формата дат, ручной маппинг, предпросмотр и мастер.
- **История прогнозов и «прогноз против факта»:** средняя ошибка по сопоставимым кампаниям, смещение, динамика точности.
- **Роли и доступы:** маркетолог (свои кампании) и администратор (пользователи, обучение, аудит). Кампании разграничены между пользователями.
- **Обучаемая модель:** ML-микросервис (CatBoost) обучается на завершённых кампаниях организации и общей выборке; у администратора есть управление обучением и исключение кампаний из него.
- **Отчёты:** экспорт прогноза в XLSX и PDF с корректной кириллицей, переносами строк и выравниванием.

## Технологический стек

### Backend
- Java 25
- Spring Boot 4, Spring Security + JWT
- Spring Data JPA (Hibernate), Flyway
- PostgreSQL 18, Apache PDFBox, Apache POI (XLSX)

### ML-микросервис
- Python 3.13, FastAPI, CatBoost, scikit-learn

### Frontend
- React 19, TypeScript, Vite 7

### DevOps
- Docker, Docker Compose

## Запуск

```bash
cd deploy
cp .env.example .env
docker compose up --build
```

Приложение доступно по адресу `http://localhost`.

Миграции Flyway применяются автоматически; отдельная настройка базы данных не требуется. Базовый сценарий демо-данных можно пересобрать генератором `db/generator/generate.py` (см. `db/generator/README.md`).

## Демо-учётные записи

| Роль | Логин | Пароль |
|------|-------|--------|
| Администратор | `admin` | `adforecastbsuir` |
| Маркетолог (демо-учётка, большой пул данных) | `demo` | `adforecastbsuir` |
| Маркетолог (личный набор кампаний) | `angejlov` | `adforecastbsuir` |

> Демо-учётка `demo` содержит основной массив кампаний и предназначена для показа. `angejlov` — личная учётка разработчика с компактным набором кампаний всех статусов.

## Архитектурные правила

- Бизнес-логика реализуется только в `backend`.
- `ml-service` не обращается к базе данных: исходные данные передаются `backend` в теле запроса.
- Обмен между компонентами — REST, JSON.
