# AdForecast

Программное средство прогнозирования окупаемости маркетинговых кампаний на основе методов машинного обучения.

Курсовой проект по дисциплине «Технологии проектирования сложных информационных систем», БГУИР.

## Структура

- `backend` – серверное приложение. Java 25, Spring Boot 4, PostgreSQL.
- `ml-service` – интеллектуальный микросервис. Python 3.13, FastAPI, CatBoost, scikit-learn.
- `frontend` – клиентское веб-приложение. React 19, TypeScript, Vite 7.
- `db` – миграции схемы, генератор данных, скрипты обслуживания.
- `deploy` – Docker Compose и переменные окружения.
- `docs` – руководства по установке и использованию.

## Запуск

```bash
cd deploy
cp .env.example .env
docker compose up --build
```

Приложение доступно по адресу `http://localhost`.

## Архитектурные правила

- Бизнес-логика реализуется только в `backend`.
- `ml-service` не обращается к базе данных, исходные данные передаются `backend` в теле запроса.
- Обмен между компонентами – REST, JSON.
